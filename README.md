# مشروع تطبيقي: تنظيف وتحليل بيانات عملاء (Python + Excel)

> **ملاحظة:** هذا مشروع تطبيقي. البيانات تجريبية بالكامل تم توليدها برمجياً، وليست بيانات عميل حقيقي.

## المشكلة
ملف بيانات عملاء (3,150 صف) فيه مشاكل واقعية: تكرارات، أرقام موبايل وتواريخ بصيغ مختلفة، أخطاء إملائية في أسماء المدن، إيميلات غير صالحة، قيم ناقصة، وقيم شاذة (عمر 250، إنفاق سالب).

## الأدوات
Python (Pandas, NumPy, regex) + openpyxl لبناء ملف Excel بتقرير ورسوم بيانية.

## خطوات التنظيف
1. توحيد المسافات في الأسماء.
2. تصحيح أسماء المدن (عربي/إنجليزي/أخطاء إملائية) بقاموس تصحيح.
3. توحيد قيم الجنس (M / male / ذكر ...).
4. توحيد أرقام الموبايل إلى صيغة 01XXXXXXXXX والتحقق منها بـ regex.
5. توحيد الإيميلات (حروف صغيرة) والتحقق من صحتها.
6. تحويل التواريخ من 5 صيغ مختلفة إلى تاريخ موحد (يوم/شهر/سنة للصيغ المصرية).
7. معالجة القيم الشاذة بقواعد عمل: العمر خارج 16–90، والإنفاق السالب أو الأكبر من 100,000.
8. حذف التكرارات: المطابقة تماماً، وكمان المكررة بصيغة مختلفة (بعد التنظيف).
9. القيم الناقصة: الأرقام تتعوض بالوسيط، والنصوص (مدينة/جنس) = "غير محدد"، وأما الموبايل والإيميل والتاريخ فتُركت فارغة عمداً.

## النتيجة
- من **3,150** صف إلى **3,007** صف (حذف 143 صف مكرر).
- تقرير كامل بكل مشكلة وعدد حالاتها والحل المطبق (شيت "تقرير التنظيف").
- شيت ملخص فيه 4 رسوم بيانية: العملاء حسب المدينة، توزيع الجنس، التسجيلات الشهرية، إجمالي الإنفاق حسب المدينة.

## الملفات
| الملف | الوصف |
|---|---|
| `generate_dirty_data.py` | يولّد البيانات الوسخة (seed ثابت فيطلع نفس الملف كل مرة) |
| `dirty_customers.csv` | الملف قبل التنظيف |
| `clean_data.py` | سكريبت التنظيف + بناء Excel |
| `customers_cleaned.xlsx` | الملف النهائي (ملخص + بيانات نظيفة + تقرير التنظيف) |
| `cleaned_customers.csv` | البيانات النظيفة بصيغة CSV |

## التشغيل
```bash
pip install pandas numpy openpyxl
python generate_dirty_data.py
python clean_data.py
```
